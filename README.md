# Mechanic City

Отдельный мобильный веб-прототип игры.

## Запуск
```bash
npm install
npm run dev
```

## Сборка
```bash
npm run build
```

## Сейчас есть
- город с 3D-машиной;
- сенсорное взаимодействие с машиной;
- рынок б/у;
- свалка;
- покупка автомобиля;
- гараж;
- ремонт;
- улучшения;
- деньги, топливо, температура и повреждения;
- нижняя мобильная навигация.

Следующий этап: полноценная 3D-сцена города, управление машиной, физика, детальная система повреждений, эвакуатор, автосервис, запчасти и сохранение.
